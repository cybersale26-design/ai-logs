# Project: Daily Affirmation Application

## Description
This repository contains the source code for a professional daily affirmation app. Users can explore categories, set a streak for repeated actions, save their favorite affirmations, and customize their affirmation themes.

### Key Features
- **Customizable Daily Affirmations**: Browse through categories such as Confidence, Gratitude, etc.
- **Save Favorites**: Keep track of affirmations that resonate with you.
- **Track Progress**: Streak counters to build daily habits.
- **Theme Management**: Aesthetic theme customizations.
- **Responsive Design**: Optimized for mobile and desktop.
- **Notification Reminder**: Users can set daily reminders.

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/cybersale26-design/ai-logs
   ```

2. Navigate to the project directory:

   ```bash
   cd ai-logs
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
